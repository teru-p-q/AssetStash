# AssetStash

[![Unity 6000.1+](https://img.shields.io/badge/unity-6000.1%2B-important.svg)](#requirements--動作環境)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE.md)

よく使うアセットやシーンオブジェクトをブックマークして、簡単にアクセスできるようにする生産性向上ツールです。
作業によって頻繁にアクセスするアセットをグループにまとめて整理したり、メモを追加して管理することができます。

## Features | 主な機能

### 登録する
- Project ウィンドウから AssetStashWindow にドラッグしてブックマークを追加
- Project ウィンドウで選択して「お気に入り追加」ボタンでも登録可能
- Assets フォルダ外のファイルもブックマーク可能

### シーン内オブジェクトのブックマーク
- Hierarchy から AssetStashWindow にドラッグ、または選択して「お気に入り追加」で登録
- 右クリック > 選択 でオブジェクトを選択。シーンが開かれていなければ確認のうえ開いてから選択
- GlobalObjectId で識別するため、シーンを閉じて開き直しても同じオブジェクトを指す
- シーンが開かれていない間は欠損扱いにしない（生死を判定できないため）。シーンを開いた状態でオブジェクトが無ければ欠損として表示
- 保存されていないシーンのオブジェクトは、識別子が安定しないため登録対象外
- GUID 列にはシーンの GUID ではなく GlobalObjectId、Path 列にはシーンのパスを表示

### 整理する
- フォルダ(グループ)を作成してブックマークを階層的に整理・分類(1階層のみ)
- フォルダ(グループ)をダブルクリックまたは F2 キーでグループ名編集
- 各ブックマークやグループにメモを追加・編集（右クリック > メモを編集）
- AssetStashWindow ツリー内のアイテムはドラッグで並び替え可能
- パス / GUID / メモ列の表示 / 非表示を切り替えてカスタマイズ
- フォルダ(グループ)の展開状態を自動保存

### 検索する
- 検索欄で名前 / パス / GUID / メモ を対象に絞り込み
- スペース区切りで複数キーワードの AND 検索
- グループ名がヒットした場合は配下をすべて表示、子がヒットした場合は親グループごと表示
- 検索中は並び順の整合が取れないため、ドラッグアンドドロップは無効

### 開く・辿る
- ダブルクリックでアセットを開く(または、右クリック > 開く)
- シーンは右クリック > 加算で開く にも対応
- 右クリック > アセットの場所を示す で Project ツリーのオブジェクト位置をハイライト
- 右クリック > エクスプローラーで開く でファイルの場所を表示（Assets 内外どちらも）
- 右クリック > パスをコピー / GUID をコピー（欠損した項目でも GUID はコピー可能）
- MonoBehaviour Script を直接 Inspector にドラッグして GameObject にコンポーネントを追加

### 複数選択
- Ctrl / Shift + クリックで複数選択し、まとめてドラッグで移動・並べ替え
- 選択したまま Delete キー、または右クリック > 選択中の n 件を削除で一括削除
- 右クリックから一括で開く / 場所を示す / パス・GUID をまとめてコピー（改行区切り）
- 一括で開く対象からシーンは除外（現在のシーンを置き換えてしまうため）
- グループを含めて選択した場合、グループは配下のブックマークを連れて移動
- 複数のスクリプトをまとめて Inspector にドラッグしてコンポーネントを追加

### 取り消し / 削除の確認
- Ctrl+Z で元に戻す、Ctrl+Y（または Ctrl+Shift+Z）でやり直し（macOS は Cmd）。右クリック > 元に戻す でも可
- 対象は追加・削除・並べ替え・リセット・メモ / グループ名の編集（最大 50 履歴、ウィンドウを閉じるとクリア）
- リセット時と、中身のあるグループを削除する際は確認ダイアログを表示

### 変更への追従と欠損の検出
- Project ウィンドウでのリネーム / 移動 / 削除に自動追従し、ウィンドウを開いたままでも名前とパスが更新される
- ブックマークに関係しないアセットのインポートでは再描画しないため、選択やスクロール位置は保たれる
- 参照先が失われたブックマークを警告アイコンと色で表示（ツールチップに GUID / パスを表示）
- 削除されたアセットは即座に欠損表示に切り替わり、復活すれば元に戻る
- 欠損がある場合のみ「欠損を削除」ボタンが表示され、まとめて登録解除が可能

### エクスポート / インポート
- ウィンドウ右上のメニュー（⋮）から JSON ファイルへの書き出し / 読み込み
- インポートは「追加」と「置き換え」を選択。どちらも Ctrl+Z で元に戻せる
- 「追加」は重複を除いて取り込み、同名グループは再利用するため、同じファイルを繰り返し読み込んでも増えない
- 重複判定はアセットが GUID、シーン内オブジェクトが GlobalObjectId、Assets 外のファイルがパス
- 取り込むのはブックマークのみ。列の表示状態は現在の設定のまま変わらない

### ショートカット

| キー | 動作 |
| --- | --- |
| ダブルクリック | アセットを開く / グループ名を編集 |
| F2 | グループ名を編集 |
| Delete / Backspace | 選択中の項目を削除 |
| Ctrl+Z（macOS は Cmd+Z） | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z（macOS は Cmd+Shift+Z） | やり直し |

ウィンドウにフォーカスがあるときのみ有効です。検索欄などへの入力中は通常のテキスト編集として扱われます。

## Installation | インストール方法

### Using Unity Package Manager (UPM)
1. Open the **Package Manager** window (`Window` > `Package Manager`).
2. Click the **"+"** button in the top-left corner.
3. Select **"Add package from git URL..."**.
4. Paste the following URL: https://github.com/teru-p-q/AssetStash.git

インストール後、`Window` > `AssetStashWindow` でウィンドウを開きます。

## Requirements | 動作環境

- Unity 6000.1 以降
- UIElements を使用しているため、UIElements がサポートされている Unity バージョンが必要です

## データの保存先

ブックマークは `EditorPrefs` に保存されます。プロジェクトのファイルとしては保存されないため、次の点にご注意ください。

- 保存先はマシンごとです。別のマシンには引き継がれません
- プロジェクト名（`Application.productName`）をキーに含むため、プロジェクト名を変更すると読み込めなくなります
- チームで共有したい場合や、バックアップを残したい場合はエクスポート機能をご利用ください
